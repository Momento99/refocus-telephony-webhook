## Полу-автоматические шаблоны для ручной отправки

Это тексты для копи-паста через wa.me-ссылку или WhatsApp Web. Не требуют Meta approval, потому что отправляются вручную из существующего треда.

### Welcome лиду (через кнопку «Отправить welcome» в карточке лида)

Зашит в кнопку — нажимаешь, открывается WhatsApp на телефоне с твоего 555, с уже введённым текстом и номером лида. Жмёшь «Отправить».

```
Здравствуйте, [имя]! 👋

Получили вашу заявку на франшизу Refocus. Свяжемся с вами в течение часа.

А пока — у вас уже должна быть наша презентация. Если что-то непонятно или появились вопросы — пишите сюда, в этом чате.

Команда Refocus · refocus.asia
```

После клика кнопка в CRM меняется на «✓ Welcome отправлен», статус карточки переходит `confirmed → contacted`, в timeline пишется `welcome_sent_manually`. Можно отправить ещё раз через кнопку «Отправить ещё раз» (с подтверждением).

### Post-call follow-up (после первого звонка с лидом)

```
Здравствуйте, [имя]!

Спасибо за разговор сегодня. По итогам:

✅ Подходящий пакет: [COMPACT / STANDARD / PREMIUM]
📅 Следующий шаг: [встреча в пятницу 14:00 по Zoom / звонок в пятницу]
📎 Полная презентация — в нашем предыдущем сообщении

Если появятся вопросы до встречи — пишите сюда, отвечу.

Команда Refocus
```

### Если лид не отвечает на звонок (1-я попытка)

```
Здравствуйте, [имя]!

Пытаюсь дозвониться по вашей заявке на франшизу Refocus.
Не получается. Когда вам удобно поговорить — сегодня вечером
или завтра в первой половине дня?

Можно ответить прямо в этом чате.

Команда Refocus
```

### Если лид не отвечает 3 дня (2-я попытка)

```
Здравствуйте, [имя]!

Хотел связаться по вашей заявке на франшизу.
Если интерес ещё актуален — напишите коротко, когда удобно поговорить.

Если решили не двигаться сейчас — тоже скажите, не буду беспокоить.

Команда Refocus
```

### Перенос встречи

```
Здравствуйте, [имя]!

К сожалению, мне нужно перенести нашу встречу с [старое время].
Когда вам удобно — [предлагаю время X] или [предлагаю время Y]?

Прошу прощения за неудобство.

Команда Refocus
```

### После встречи / Zoom (с конкретным предложением)

```
Здравствуйте, [имя]!

Спасибо за встречу. По итогам:

Рекомендую вам пакет [X] потому что [Y].
Полный бюджет — [сумма] сом ([эквивалент в $]).
Прогноз прибыли — [сумма] сом в месяц с базовым трафиком.

Что у нас дальше:
1. Готовите финансовый план (помогу если нужно)
2. Согласовываем помещение (если ещё нет)
3. Подписываем договор — выделю день на этой неделе

Какой шаг хотите сделать первым?

Команда Refocus
```

### Win-back через 6 месяцев (для lost-лидов)

```

Полгода назад вы интересовались нашей франшизой, но было рано.

### Если лид сменил решение (после converted решил выйти — крайний случай)

```

Понял ваше решение. Если можете — расскажите коротко, что повлияло.
Это нам важно, чтобы быть лучше для следующих партнёров.

Если что-то изменится в будущем — двери открыты.

## Правила тона

- **Без панибратства:** «Здравствуйте», не «привет, дружище»
- **Без воды:** прямо к делу
- **Без капс-лока и !!!**: спокойно
- **Без эмодзи в избытке:** одна на сообщение макс
- **Без фейковой срочности:** не «осталось 3 места» когда их нет
- **С именем:** всегда «Здравствуйте, [имя]» а не «Здравствуйте»
- **Подпись:** всегда «Команда Refocus», не личные имена (защищаем единый тон)

## Технические заметки

### Когда возвращаешь шаблон с переменными в Meta форме approval

Категория всегда: **UTILITY** (потому что это сервисные уведомления о статусе процесса, не маркетинг)
Язык: **Russian (ru)**
Для каждой переменной {{N}} нужно дать **пример** в Meta форме:
- {{1}} = Айбек
- {{2}} = +996 500 12 34 56
- ...

### Что делать пока шаблоны не одобрены

В админке CRM появится временная кнопка «Отправить через wa.me» — открывает WhatsApp Web с готовым текстом. Менеджер вручную нажимает «Отправить». Не идеально, но работает.
